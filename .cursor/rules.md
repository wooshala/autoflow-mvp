# PROJECT RULES (ALWAYS APPLY)

이 프로젝트의 아키텍트 기준은 아래 문서에 정의되어 있다:

- /ai/ARCHITECTURE.md
- /ai/INVARIANTS.md
- /ai/DECISIONS.md
- /ai/TASK_GATE.md

모든 작업은 반드시 위 문서를 먼저 읽고 시작한다.

## 필수 절차

코드 수정 전에 반드시 아래 형식으로 먼저 답하라:

[PRE-CHECK]
- Phase:
- 변경 목적:
- 수정 파일:
- 기준선 영향:
- 위반 가능성:
- 허용 여부: YES / NO

## 금지

- PRE-CHECK 없이 코드 작성 금지
- INVARIANTS 위반 코드 작성 금지
- 기준선 불안정 상태에서 기능 추가 금지

## 행동 규칙

- 규칙 위반 가능성이 있으면 코드를 수정하지 말고 먼저 보고한다
- 판단이 애매하면 DECISIONS.md 기준으로 판단한다
- 문서와 충돌하면 문서를 우선한다

--------------------------------------------------

## MANDATORY POST-STEP (CRITICAL)

모든 작업 완료 후 반드시 아래를 수행한다:

1. /ai/PROJECT_STATE.md 업데이트
   - 현재 상태
   - 변경된 내용
   - 다음 단계

2. /ai/SESSION_LOG.md 기록
   - 이번 작업 내용
   - 시도한 것
   - 결과
   - 문제/교훈

이 단계가 수행되지 않으면 작업은 완료된 것으로 간주하지 않는다.

코드 수정 → 테스트 → md 업데이트  
이 순서를 반드시 지킨다.
