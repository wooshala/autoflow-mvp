# TASK GATE

모든 작업은 아래 형식으로 먼저 점검한 뒤 시작한다.

## 작업 시작 전 체크
1. 이번 작업은 어떤 Phase인가?
2. 이번 작업이 ARCHITECTURE.md와 충돌하는가?
3. 이번 작업이 INVARIANTS.md를 위반하는가?
4. 수정 파일은 무엇인가?
5. 채팅 기준선을 건드리는가?
6. 롤백 가능한가?
7. 실기기 테스트 항목은 무엇인가?

## 응답 형식

작업 전 반드시 아래 형식으로 먼저 작성:

[PRE-CHECK]
- Phase:
- 변경 목적:
- 수정 파일:
- 기준선 영향:
- 위반 가능성:
- 허용 여부: YES / NO

허용 여부가 NO이면 코드 수정 금지.
